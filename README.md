## Descrição
Este projeto simula um mini catálogo de materiais inspirado no módulo SAP MM.  
Permite inserir, editar e deletar materiais em tempo real, utilizando HTML, CSS e JavaScript.

## Funcionalidades
- Inserir materiais com validação.
- Editar materiais via prompt.
- Excluir materiais individualmente.
- Excluir todo o catálogo.
- Interface inspirada no SAP Fiori.
